# 正式发布与维护

更新日期：2026-10-20。正式发布地址：<https://langxin11.github.io/>。

## 维护方式

博客采用单仓库统一维护（仓库为 `langxin11/langxin11.github.io`），直接管理文章、图片、个人外观配置、主题依赖与部署工作流。本地提交并推送到 main 分支后，由 `.github/workflows/deploy.yml` 自动在 Node.js 24 下安装依赖、检查、构建并发布到 GitHub Pages。

日常修改正文：`posts/`。修改外观：`site/shirones/config/`。修改关于页：`spec/about.md`。不在 `node_modules` 或生成内容中修改文件。

目录点击的站点修订位于 `site/src/components/atoms/blog/TocList.astro`；它统一处理手机端与侧栏的锚点点击，先关闭目录、聚焦章节，再定位到导航下方，避免多个滚动处理争用。同路径组件覆盖由主题支持，主题升级后需重新检查其接口与跳转效果。

首次在 `site/` 执行 `pnpm install --frozen-lockfile`，随后 `pnpm dev` 启动本地预览。开发服务会监听文章、关于页和图片源目录；保存后同步生成副本。开发预览允许查看草稿，正式构建会过滤 `draft: true`。旧的 4321 端口预览也保留，草稿有明显提示。

## 自动发布

将修改提交并推送 `main` 分支后，GitHub Actions 的 `deploy.yml` 会即时触发自动构建与部署。未引入额外的个人访问令牌或部署密钥，直接使用环境赋予的 GITHUB_TOKEN。

也可在 GitHub Actions 页面手动点击 `Run workflow` 触发部署。

每次公开构建自动验收：文章数量与源稿一致；7 个旧文章地址均存在；所有文章图片有本地文件；无 KaTeX 错误；RSS、Atom 和站点地图使用正式地址；草稿未生成页面，也未进入订阅与地图。失败时保留上一次成功的网站。
